# 需求文档

## 介绍

儿童积分系统是一个游戏化的家庭积分管理平台，旨在通过积分奖励机制鼓励儿童养成良好的行为习惯。系统支持家长和儿童两种角色，家长可以自定义行为规则、管理积分商城，儿童可以查看积分、兑换礼品并获得成就勋章。整体UI风格充满童趣和游戏感，支持多种主题切换。

## 需求

### 需求 1 - 用户角色管理

**用户故事：** 作为系统用户，我希望能够以不同角色（家长/儿童）登录系统，以便访问对应的功能模块。

#### 验收标准

1. 当用户访问系统时，系统应当提供角色选择界面
2. 当家长登录时，系统应当显示家长管理界面
3. 当儿童登录时，系统应当显示儿童游戏化界面
4. 当用户选择角色后，系统应当验证身份并跳转到对应界面

### 需求 2 - 行为规则管理

**用户故事：** 作为家长，我希望能够自定义儿童的行为规则和对应的积分值，以便建立个性化的奖惩机制。

#### 验收标准

1. 当家长创建行为规则时，系统应当允许设置行为名称、描述、加分/减分数值
2. 当家长修改规则时，系统应当要求提前一天设定并需要儿童确认
3. 当双方确认规则后，系统应当在第二天凌晨0点自动生效
4. 当家长删除规则时，系统应当提供确认提示
5. 如果行为每周完成3次以上，系统应当自动颁发对应勋章

### 需求 3 - 积分商城管理

**用户故事：** 作为家长，我希望能够管理积分商城的商品，包括实物和虚拟奖励，以便为儿童提供多样化的兑换选择。

#### 验收标准

1. 当家长添加商品时，系统应当支持实物玩具和虚拟行为两种类型
2. 当家长设置虚拟奖励时，系统应当支持"游戏时间延长"、"亲子活动"、"自选玩具"等类型
3. 当家长管理商品时，系统应当提供上架、下架、删除、编辑积分值功能
4. 当商品状态改变时，系统应当实时更新儿童可见的商城列表

### 需求 4 - 积分记录管理

**用户故事：** 作为家长，我希望能够给儿童的日常行为进行积分操作，以便实施奖惩机制。

#### 验收标准

1. 当家长评价儿童行为时，系统应当根据预设规则自动计算积分变化
2. 当系统初始化时，系统应当建议给儿童设置初始积分
3. 当每周结束时，系统应当建议家长发放固定的周积分奖励
4. 当积分发生变化时，系统应当记录详细的变更日志

### 需求 5 - 儿童积分查看

**用户故事：** 作为儿童，我希望能够查看自己的积分情况和历史记录，以便了解自己的表现。

#### 验收标准

1. 当儿童登录时，系统应当显示当前总积分
2. 当儿童查看历史时，系统应当显示积分增减记录和兑换记录
3. 当儿童查看记录时，系统应当按时间顺序展示详细信息
4. 当积分发生变化时，系统应当实时更新显示

### 需求 6 - 礼品兑换申请

**用户故事：** 作为儿童，我希望能够申请兑换积分商城的礼品，以便获得奖励。

#### 验收标准

1. 当儿童浏览商城时，系统应当显示所有可兑换的商品和所需积分
2. 当儿童申请兑换时，系统应当检查积分是否足够
3. 如果积分足够，系统应当发送兑换申请给家长审批
4. 当家长审批后，系统应当扣除对应积分并记录兑换历史

### 需求 7 - 成就勋章系统

**用户故事：** 作为儿童，我希望能够获得各种成就勋章，以便增加游戏的趣味性和成就感。

#### 验收标准

1. 当儿童完成特定行为3次以上时，系统应当自动颁发对应勋章
2. 当系统颁发勋章时，系统应当支持"独立能手"、"学习之星"、"运动之星"等预设勋章
3. 当家长自定义勋章时，系统应当允许设置勋章名称、图标、获得条件
4. 当儿童获得勋章时，系统应当显示庆祝动画和通知

### 需求 8 - 系统个性化定制

**用户故事：** 作为家长，我希望能够自定义系统的文案和图片，以便营造温馨的家庭氛围。

#### 验收标准

1. 当家长自定义文案时，系统应当允许修改各个界面的提示文字
2. 当家长上传家庭合照时，系统应当将其设置为首页背景图
3. 当设置保存后，系统应当在所有相关界面实时生效
4. 当儿童查看时，系统应当显示个性化的鼓励文案

### 需求 9 - 主题切换功能

**用户故事：** 作为儿童，我希望能够选择不同的游戏主题，以便获得个性化的使用体验。

#### 验收标准

1. 当儿童选择主题时，系统应当提供"植物大战僵尸"和"我的世界"两种选项
2. 当选择植物大战僵尸主题时，系统应当显示"太阳花"、"冰西瓜"、"僵尸博士"等相关元素
3. 当选择我的世界主题时，系统应当显示对应的游戏元素和按钮样式
4. 当主题切换后，系统应当保存用户偏好并在下次登录时应用

### 需求 10 - 游戏化UI设计

**用户故事：** 作为儿童用户，我希望系统界面充满童趣和游戏感，以便提高使用的趣味性。

#### 验收标准

1. 当儿童使用系统时，系统应当提供色彩丰富、卡通风格的界面
2. 当进行操作时，系统应当提供动画效果和音效反馈
3. 当显示积分时，系统应当使用游戏化的图标和进度条
4. 当获得奖励时，系统应当播放庆祝动画和音效
